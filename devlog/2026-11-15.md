# 2026-11-15：最难的是手柄

## 今天的结论

游戏本身不是问题，输入是。R36S 的摇杆（`adc-joystick`）和按键（`gpio-keys`）是**两个独立输入设备**，
SDL/RetroArch 不会把它们合并成一个手柄。选摇杆设备 → 所有按键失效；选按键设备 → 摇杆失效。

## 黑屏不是核心的问题

换掉 ArkOS 的 `gpsp_ezode_mod` 后仍然黑屏，日志每帧刷 `c_RkRgaBlit failed`。
原因：厂商 RetroArch 链接了 `librga.so.2`，用 Rockchip 私有 2D 加速器拷贝画面；主线内核没有 RGA 驱动。
**解决**：换成 Debian 官方 RetroArch 1.20，走 KMS + panfrost 渲染。

第二个坑：启动器继承的 `LD_LIBRARY_PATH=/opt/treeos-compat/lib` 里的旧 `libva`
顶掉系统新库，导致 `vaMapBuffer2` 符号错误、游戏闪退。启动器里 `unset LD_LIBRARY_PATH` 解决。

## 输入：从虚拟手柄到虚拟键盘

先尝试用户态合并成虚拟手柄，但 RetroArch 给设备的按键索引和内核键码对不上，反复试错。
最终方案：`padmerge.py` 造一个**虚拟键盘**，把实体键翻译成键盘键，RetroArch 用
`input_player1_a = "x"` 这类明确绑定。摇杆超过死区后翻译成方向键。

实测键码（抓 event 流确认）：A=305 B=304 X=307 Y=308，L1=310 R1=311，
方向 544-547，Select=704 Start=705，L3=706 R3=707，FN=708。

## 存档被写成空数据

一个 128 KiB 存档变成全 `0xFF`。链条：开过 `sort_savefiles` → 存档被移到 `gpSP/` 子目录 →
根目录读到空存档 → 退出时把空 SRAM 写回。已从电脑备份恢复。
**根因未证明**，只是缓解：关闭排序、存档放内容目录。反复保存/退出/重启测试前不标绿。

## 中文名 ZIP

GBK 编码文件名的 zip 在 RetroArch 里解压失败（日志乱码）。用 Python 显式按 GBK 解码解压，
并把原 zip 移出扫描目录，否则列表里同一个游戏会出现两份。
