# 2026-11-19 · Flash 设置界面重做：一柄多键、按住绑定、现成图标

Flash 页面游戏在 R36S 上已经能跑，但“每个游戏都要手工调键”一直没解决。今天把设置界面和输入层重做了一版，目标只有一个：把调键从必经路径变成例外。

## 之前的问题

- 鼠标左右键藏在“高级选项”里，和按键映射分家
- 一个手柄键只能绑一个键盘键，A 映射了 J 就不能同时要空格
- 鼠标点击和键盘绑定二选一，A 不能既开枪又发键
- 设置页保存后返回游戏，实际还在用旧映射（session 没重新编译）
- 保存会往 v3 profile 里插第二行 schema，之后读配置直接报重复键
- 右上角永远写着“启动器设置”，进哪一页都不变

## 现在的行为

### 设置界面

- 鼠标左键/右键并入“按键映射”页，列表 16 项（14 个手柄键 + 两个鼠标键）
- 选中鼠标行按 A，进入独立绑定页：**按住任意手柄键约 2 秒**，进度条走满即绑定
- A/B/X/Y/L1/R1/L2/R2/START/SELECT 全部可绑；FN 或 START+SELECT 取消
- 页头跟随页面：启动器设置 / 按键映射 / 选择键盘键 / 高级选项
- 图标换成 Kenney *Input Prompts*（CC0）：ABXY 按实机配色染色，方向键四向十字，鼠标左右键自带按下标记

### 一柄多键

- profile 支持列表：`south=74,32`（A 同时发 J 和空格，最多 6 个）
- 键盘页：A 短按添加/取消，长按 A 移除；已选键绿色标记；列表显示 `J/空格`
- 鼠标与键盘可以同时：A 可以既是左键，又发 J + 空格
- 只写用户真正改过的行，避免把模板默认值写死进 profile

### 启动链路

- 保存后 `flash-return2.sh` 重新编译 session，再回增强运行时（之前是旧映射）
- 释放 DRM 后等 2 秒再起 Weston（之前会卡在 GL 初始化、Wayland socket 不出）
- 设置界面初始化失败回 ES，不再盲目重开游戏
- `flashcfg` 升 schema 3；修复 `set` 写坏 schema、`migrate` 重复行
- `padinput` 支持多键、点击与键盘并发、鼠标速度来自 session；设备名匹配放宽到 `gamepad/joypad/retrogame/r36s`

## 验证

- 测试 profile `south=74,32` → `session.profile` 保留列表；`padinput` 输出 `{305: [36, 57], ...}`
- 设置保存 → Weston 正常起、Ruffle 480×360、`/tmp/padinput.cfg` 为 `stick=arrows pointer=right speed=6.0`
- 图标 10/10 解码；`/opt/flashmenu/icons/`

## 还没验收

- 经典后端仍未消费 session 模板，只有增强模式吃新映射
- 20 次冷启/退出/Fn 往返回归
