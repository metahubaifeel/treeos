### 三条边界的结论（2026-11-13）

| 问题 | 结论 |
|---|---|
| 汉化 = TreeOS 吗？ | 不是。汉化是第 2 阶段的一小块，TreeOS 是自己定基线、自己发版 |
| 能不刷机、只热更新吗？ | **glibc 以上**随便热更新（脚本、菜单、主题、预设包）；**换底座必须重刷一次**，之后又回到能热更新 |
| ArkOS4Clone 会变成 TreeOS 吗？ | 留在旧底座 = 它的衍生版（要跟上游）；**换底座之后**只剩它的菜单层和脚本层，才是 TreeOS（分叉点就在换底座） |

## 它不是刷机工具

| | TreeOS | 拙木刷机助手 |
|---|---|---|
| 是什么 | **系统本身**（跑在掌机里的） | **工具**（跑在电脑上的） |
| 代码放哪 | `11_TreeOS/` | `12_刷机助手/` |
| 用户拿到 | 一个镜像 / 一次在线升级 | 一个 exe / AppImage |

**两个独立项目，各自发版，不互相依赖。** 刷机助手可以刷任何系统，不只 TreeOS。

## 差异化（唯一要死守的一条）

> **刷完就能开机。**

拙木 2026-11-12 亲历的三个坑，就是全世界的三个坑：

1. **三个分卷 + 两层解压**，坏一个就天书报错
2. **刷完黑屏** —— 因为必须先在电脑上跑 `dtb_selector`，卡上才会写 `boot.ini` / `Image` / `.dtb`。不跑就 `dtb load fail`
3. **全英文**，中文搜不到答案

**TreeOS 要在镜像层面消灭第 2 条**：镜像刷完，启动文件就已经在卡上了。

## 体验目标（拙木定的，补于 2026-11-14）

朝着"这台机器用起来舒服"去的，不是功能清单：

- **刷完就能开机**，不用回电脑
- **开机直接进菜单**，手柄不用配（已实现）
- **开机任何时刻不黑屏**（logo / 开机动画齐全）
- **屏幕亮度可调**，晚上不刺眼；最低能暗到几乎不亮
- **指示灯可关/可调**，夜里不亮点
- **音量可调**，有 OSD 提示
- **待机有动画轮播**（闲置一段时间自动播放，按任意键回来）
- **主题可在机器上随时切**，不用连电脑
- 中文，所有菜单和设置都能看懂

## 三条验收红线（自己定的，不许破）

1. **刷完就能开机** —— 不需要回电脑再跑任何工具
2. **启动期间持续有画面** —— 从上电到菜单，屏幕不应长时间无内容；异常时要有可读的故障提示（不能承诺"永不黑屏"，内核切换/关机瞬时会黑）
3. **主题能在机器上随时切** —— 不许要求连电脑

## 已知硬件事实（别再查一遍）

- 4 个可用 GPIO 在**未焊的 flash 焊位**上：`GPIO32 / 33 / 36 / 41`（对应 `GPIO1_A0/A1/A4/B1`）
- 软件层面已验证：`export` 成功、可设 `out`、写读正确、无驱动占用
- **未验证**：焊盘上是否真有电平变化（需要万用表实测）
- OTG 5V 由 `vcc_host`（regulator-fixed，GPIO 控制）供电，旧固件 dtb 里没有这个节点 → 口子和 WiFi 一起断电
- WiFi 芯片是 **RTL8188EU（USB `0bda:8179`）**，挂在内部 hub `1a40:0101` 上
