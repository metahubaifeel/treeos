# 其他系统值得抄的功能（备查，慢慢做）

> 2026-11-15 建立。拙木的原话：**"好东西你要记录下来，因为你上下文有限，以后可以慢慢做。"**
> 原则不变：**功能宁少勿多**，新功能让冷启动多 2 秒就不进默认镜像。

## 一、已核实：本机 ES 里就有（ArkOS 血统，不用重造）

来源：直接在 `/usr/bin/emulationstation/emulationstation` 二进制里 grep 到的菜单项（2026-11-15 实测）。

| 功能 | 用途 | 对应需求 |
|---|---|---|
| **JOYPAD TEST** | 摇杆/按键测试页，验机、查漂移 | N2 ✅ 已内置 |
| **JOYSTICK DEAD ZONE** | 死区调节（可填 10–1800） | 防漂移 ✅ |
| **JOYSTICK CALIBRATION** | 摇杆范围校准（两步：静止采样中心 → 转满圈） | 防漂移 ✅ |
| **CONFIGURE INPUT** | 手柄重映射向导 | ✅ |
| **BUTTON LAYOUT ADJUSTMENT** | 互换 A/B、X/Y | ✅ |
| **ANALOG STICK EMULATION** | 用一个按键模拟摇杆方向 | ✅ |
| **VOLUME KEY ADC CALIBRATION** | 音量键 ADC 校准（厂商硬件路径，我们是自己写的 keys 脚本，不适用） |
| **SD2 卡菜单**（READ SD1 AND SD2 / 仅 SD2） | 系统内切卡、挂载第二张卡 | N5 的原型 |
| 系统更新（ARE YOU SURE YOU WANT TO UPDATE THE SYSTEM?） | ArkOS 的在线更新入口 | 我们暂缓，见 OTA 决策 |

**结论：N2（摇杆测试）和死区/校准不需要开发，只需要保证菜单入口可见、中文可读。**

## 二、待调研清单（还没核实，别当真）

这些是下一步要拿别人系统实际对比的，**调研时逐条填**：

| # | 系统 | 要看的点 | 为什么 |
