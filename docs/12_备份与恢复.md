# TreeOS 备份与恢复

> 创建：2026-11-15。SD 卡是消耗品，频繁插拔会坏。**每次重大改动后都要备份。**
> 原则：备份文件一律放电脑 `.backup/`，别留在设备或临时目录。

## 一、备份什么

| 内容 | 位置 | 重要性 |
|---|---|---|
| **整卡镜像** | `.backup/treeos-mothercard-*.img.gz` | 最高：系统、配置、驱动全在里面 |
| rootfs 压缩包 | `.backup/rootfs-*.tgz` | 高：用于打新镜像 |
| 启动文件 | `.backup/bootfiles/`（Image/boot.ini/dtb/logo） | 高 |
| 游戏存档 | `.backup/EASYROMS-*/gba/*.srm` 等 | 最高：**丢了不可重建** |
| ES 配置 | `/etc/emulationstation/`、`~/.emulationstation/` | 中 |
| RetroArch 配置 | `~/.config/retroarch/retroarch.cfg`、`assets/` | 中 |

## 二、整卡备份（推荐，最省心）

```bash
# 插上母卡，确认设备号（lsblk）
sudo bash 11_TreeOS/scripts/backup-card.sh /dev/sdX
```

产物：`.backup/treeos-mothercard-YYYYMMDD-HHMM.img.gz` + `.sha256`

耗时：59GB 卡约 20-40 分钟，压缩后约 8-15GB。

## 三、恢复整卡

```bash
gunzip -c .backup/treeos-mothercard-xxxx.img.gz | sudo dd of=/dev/sdX bs=16M status=progress
sync
```

**恢复会覆盖整张卡**，先 `lsblk` 确认目标设备号，别写错盘。

## 四、只恢复某个文件

```bash
# 挂载备份镜像
sudo losetup -fP .backup/treeos-mothercard-xxxx.img   # 或先 gunzip
# 然后挂载分区、拷文件，例如恢复一个存档：
sudo mount /dev/loop0p3 /mnt
cp /mnt/gba/xxx.srm /media/amd/EASYROMS/gba/
```

## 五、打新镜像（v3+）

```bash
# 1) 从母卡打包 rootfs
sudo tar -C /media/amd/treeos-root -czf /tmp/rootfs-v3.tgz .
# 2) 构建镜像
sudo bash 11_TreeOS/scripts/build-image-v3.sh
# 产物 /tmp/treeos-v3.img，拷到卡或直接 dd 到新卡
```

## 六、教训（血泪）

- **存档曾被 RetroArch 写空覆盖**，靠电脑上的 `.backup/EASYROMS-*/` 才救回来
- 备份完成前不要拔卡、不要刷机
- 每次改完输入/存档/字体等关键配置，先备份再继续折腾
