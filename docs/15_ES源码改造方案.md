## 二、D16 · WiFi 键盘左右反向（已打补丁）

**文件**：`es-core/src/guis/GuiTextEditPopupKeyboard.cpp`（约 251–270 行）

**原逻辑**：在键盘网格上，左键直接跳到行尾、右键跳到行首（循环换行）→ 表现为左右反向。

**补丁**：只在光标已到边缘时循环，否则交给网格正常移动一格。

```cpp
else if (config->isMappedLike("left", input)) {
    if (mGrid.getSelectedComponent() == mKeyboardGrid) {
        Vector2i curCursor = mKeyboardGrid->getCursor();
        if (curCursor.x() == 0) {           // 只在最左才循环
            mKeyboardGrid->setCursorTo(Vector2i(kbUs[0].size() - 1, curCursor.y()));
            return true;
        }
    }
}
else if (config->isMappedLike("right", input)) {
    if (mGrid.getSelectedComponent() == mKeyboardGrid) {
        Vector2i curCursor = mKeyboardGrid->getCursor();
        if (curCursor.x() >= (int)kbUs[0].size() - 1) {   // 只在最右才循环
            mKeyboardGrid->setCursorTo(Vector2i(0, curCursor.y()));
            return true;
        }
    }
}
```

## 四、N3 · 主题预览

**文件**：`es-app/src/guis/GuiMenu.cpp`，主题选择块（约 974–995 行）

现状：

```cpp
auto themeSets = ThemeData::getThemeSets();
auto theme_set = std::make_shared<OptionListComponent<std::string>>(mWindow, _("THEME"), false);
...
s->addWithLabel(_("THEME"), theme_set);
s->addSaveFunc([...] { /* 切主题 */ });
```

**方案**：在 `s->addWithLabel(...)` 之后追加一个 `ImageComponent`：
1. 取当前选中主题的 `ThemeSet::path`（`es-core/src/ThemeData.h:82`）
2. 预览图路径：`<path>/preview.png`（缺省显示占位图）
3. 给 `theme_set` 设置 `setSelectedChangedCallback`，实时换图
4. 图片尺寸适配设置页宽度（约 400×300），居中显示

**预览图生成**：用 ES 逐主题启动并截图（或手工放），文件名统一 `preview.png`；
v4 镜像内置主题各带一张；缺失时显示「无预览」。

## 五、实施顺序

1. 设备原生编译**未修改**的源码 → 确认能跑（基线）
2. 只应用 D16 补丁 → 测试 WiFi 键盘左右
3. 应用 N3 预览 → 测试主题页
4. 应用 N10 菜单结构 → 测试全部入口
5. 备份/回滚：原二进制存 `/usr/bin/emulationstation/emulationstation.arkos`，
   出问题直接换回

## 六、风险

- ES 依赖 ArkOS 的 `/opt/treeos-compat` 库路径（VLC、libmali），编译时链接环境要一致
- 替换二进制后主题/字体路径不变，但资源目录若缺文件会黑屏——先跑未修改版本验证
- 1GB 内存编译可能 OOM：`make -j1`，必要时 `zramctl` 确认 swap 生效

## 七、第四轮评审后的修订（2026-11-16，以此为准）

### 7.1 阶段化构建（不再"一次编译解决三个问题"）

| 阶段 | 内容 | 放行条件 |
|---|---|---|
| **B0** | 固定上游 commit，原版编译，不改功能 | 构建成功；启动/进游戏/退出/设置保存正常 |
| **B1** | 只加 D16 | 键盘导航全量回归（每行左右、首尾循环、特殊键、短按长按、十字键+摇杆） |
| **B2** | 加 N3 主题预览 | 主题页布局、切换、保存/取消正常 |
| **B3** | 加 N10 菜单结构 | 旧入口→新入口映射表逐项验收 |
| RC | 打进镜像 | 首启、扩容、重启、游戏进出、异常恢复 |

**每阶段保留**：Git commit、构建日志、二进制 sha256、安装包、测试记录。

### 7.2 编译环境

- **不在 v4 干净镜像上装开发依赖**：v4 是发布基线，另用一张**开发卡**做原生编译
- 设备原生编译只用于首次打通；长期迁移到 PC 交叉编译（固定 sysroot + 工具链）
- `-j1` 编译前退出 ES，监控内存/OOM/温度/磁盘

### 7.3 主题预览（N3）——改为独立页面

不做"设置页里塞大图"，改为**独立「主题选择」页**：

- 左侧/上方主题列表，右侧/下方当前选中主题截图
- 底部：应用 / 返回
- 光标移动只换图，**保存后才应用主题**；取消不改
- 预览图 `<theme>/preview.png`，缺失显示占位；手工压缩 3–5 张起步，不做自动截图系统
- 与 N10 顶层「主题」入口一致

### 7.4 主菜单任务映射（N10 先定表再改代码）

| 顶层 | 必须覆盖 |
|---|---|
| 游戏库 | 更新游戏列表、集合管理、搜索/筛选、封面与元数据刮削 |
| 主题 | 选择、预览、应用、主题变体设置 |
| 设置 | WiFi、声音、亮度、语言、输入映射、界面行为、系统信息 |
| 工具 | 文件维护、诊断、备份/恢复、高级维护 |
| 电源 | 关机、重启（有可靠实现才提供休眠） |

- **不能隐藏**：联网、输入配置、更新等正常任务
- 刮削属于常见任务，不建议默认当高级功能隐藏
- 高级开关 `TreeOSAdvancedMenu` 只控制维护项，本身要有可发现入口
- 改 `.po` 后确认 `.mo` 生成并部署

### 7.5 交付与回滚

- 产物做成**版本化 `.deb`**（含二进制、资源、翻译、启动脚本、配置模板）
- 安装前停 ES；保留 `/usr/bin/emulationstation/emulationstation.arkos` 原版
- 回滚清单：二进制、资源、配置、启动脚本、包版本
- 验证 `ldd`/`readelf`，确认没有链接到开发环境路径或目标镜像不存在的库

### 7.6 基线核实（B0 前）

- 固定上游 commit 与当前已安装二进制的来源/构建选项
- 记录现有 ES 的启动脚本、`LD_LIBRARY_PATH`、资源目录
- 确认"原版源码编译"与现有二进制行为一致，否则基线不成立
