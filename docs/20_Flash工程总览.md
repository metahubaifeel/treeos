# Flash 怀旧页游工程：目标、架构与边界

更新：2026-11-18

## 目标

把 4399 时代的 Flash 页游做成 **R36S 上可离线运行的本地版**：
EmulationStation 里一个「Flash」分类，选中即玩，手柄可用，存档留在本机。

## 运行时架构

```
ES（Flash 分类）
  └─ /roms/ports/rufflehandheld/runtime/launch.sh <game.swf>
       ├─ 读取全局 default.profile
       ├─ 按文件名匹配 custom/<name>.profile（支持 aliases）
       ├─ Ruffle native 运行时（DRM/KMS 直出，无 X、无浏览器）
       └─ gptokeyb2：方向键=鼠标移动，A=左键
```

- **输入**：内核层 `odroidgo3-joypad` 把摇杆和按键合并成一个标准手柄；
- **映射**：全局默认 + 逐游戏覆盖，两者都由启动器自动加载，用户不需要手工放文件；
- **左摇杆三档**：鼠标 / WASD / 方向键，按游戏保存在 `<stem>.stick`；
- **设置 UI**：游戏内按 FN → 结束游戏 → 设置界面（真实键盘布局选键、摇杆三档）→ 保存 → 重新加载。

> 说明：这台机器的冻结 Ruffle 核心收不到 SDL 按钮事件，所以鼠标点击走 gptokeyb2 注入。
> 副作用是可能出现两个指针（Ruffle 自身光标 + 注入光标），不影响操作。

## 边界与合规

- 只做运行时、启动器、映射工具；**不分发 SWF、音频、字体、汉化包**；
- 不预装、不镜像、不代用户下载游戏资源；游戏由用户自备并自行确认授权；
- 不碰账号体系、不破解付费内容；
- 对外只写「已验证的样本」，不承诺「所有 Flash 都能玩」。

## 已知风险

1. **内存**：1GB + A35，重游戏（3.2 级）要靠 ext4 swap，切场景会读卡；
2. **兼容性**：Ruffle 对 AS2/AS3、外部资源、字体、服务器依赖的支持差异很大；
3. **内容供给**：能离线跑的、需要后端的、根本不是 Flash 的，必须分类承诺；
4. **视觉**：双指针、部分游戏分辨率/缩放需要逐款调。
