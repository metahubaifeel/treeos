## 四、踩坑记录

- 冻结核心无 fontconfig；SWF 注入 DefineFont 无效（deviceFont 只问后端，已实测）
- Ruffle desktop 用 winit，必须 Weston/X11；纯 KMSDRM 不行
- cross 镜像 OpenSSL 1.0.2 / freetype 2.6.1 太老 → rustls + ring、关闭 freetype
- `rustls-no-provider` 必须手动 `install_default()`
- Weston 截图需 `--debug` + `weston-screenshooter`；光标需 adwaita-icon-theme
- `pkill -f` 会匹配到 SSH 自己的命令行，多次把会话杀掉 → 改用 `pkill -x` 或固定脚本
- 残留 wayland socket 会造成「假就绪」，启动器必须先删 socket 再等进程

## 十二、造梦西游降渲染分辨率（2026-11-19）

- 关键发现：`--quality low` 只影响 Flash 舞台质量，**不等于降低渲染像素**；窗口尺寸才是
- 首次改错 profile：游戏启动文件名是 `0_L4399Main_gamefile-offine-mod2.swf`，启动器按文件名找 profile，
  写进 `zmxy.profile` 不生效
- 第二个 bug：`flashcfg dump --shell <profile>` 把 `--shell` 当 profile，读到全局默认，
  导致启动器一直用 640×480；已修为取第一个非 `--` 参数
- 修正后实测：`--width 480 --height 360`，RSS 466MB→439MB，用户反馈「快很多」
- 正确 profile：`profiles/custom/0_L4399Main_gamefile-offine-mod2.profile`（viewport=480x360, quality=low）

补充（320×240 实测）：比 480×360 **更慢**。原因是 Weston 放大到 640×480 的额外开销抵消收益；
同时温度 84.6°C 贴近 85°C 降频线、GPU 仅 400MHz。结论：480×360 为造梦最优档，再降像素无效。

## 十五、板级参数化清单（0.2，RK3566 接入用）

R36S 与 RG353V 不共用内核，启动器只共用用户态。0.1-preview 期间冻结 R36S 行为，
参数化在 0.2 做；接口先定成一份 `board.conf`（key=value），由 `treeos-flash` 最先读取，
环境变量可覆盖。

| 配置键 | R36S | RG353V |
|---|---|---|
| `rom_root` | `/roms` | `/storage/roms` |
| `profile_dir` | `/roms/ports/rufflehandheld/profiles` | 板级可配 |
| `runtime_dir` | `/run/ruffle-weston` | `/run/0-runtime-dir` |
| `wayland_display` | `wayland-1`（weston kiosk） | 从 ES 会话继承 |
| `swaysock` | 无 | `/run/0-runtime-dir/sway-ipc.0.sock` |
| `fullscreen` | `weston` | `sway`（`app_id=rs.ruffle.Ruffle`） |
| `ruffle_bin` | `/opt/ruffle-new/ruffle_desktop` | 板级可配 |
| `fontconfig_file` | 系统 fontconfig | 随包 `fonts.conf`（DroidSansFallback） |
| `pad_names` | `r36s_Gamepad` | `retrogame_joypad`（匹配已含 joypad/retrogame） |
| `es_launch` | `sudo flash-es-launch` + `es_systems.cfg` | Ports 脚本直接 exec |
| `es_unit` | `treeos-emulationstation` | `essway` |
| `icon_dir` / `log_dir` | `/opt/flashmenu/icons` / `/tmp` | 板级可配 |
| `backends` | `classic,enhanced` | 仅 `enhanced`（经典核心未验 GLES/ABI） |

原则：
- 先记录实机加载的 DT/panel/cmdline/DRM mode，再换根；不混装 R36S 6.15.6 与 353V DTB
- 353V 从 ES 会话继承 Wayland 环境，不硬编码 `XDG_RUNTIME_DIR`/`WAYLAND_DISPLAY`
- 353V 只标增强线；两个 Ports 各 10 次连启/退通过后才谈双线
- 测试文件（`/storage/ruffle-test`）保留给 0.2，但 SWF 不得放在 `/storage/roms` 扫描目录

RG353V 侧给出的 `board.conf` 参考值（路径以实机为准）：

```ini

runtime_dir=/run/0-runtime-dir
wayland_display=wayland-1        # 优先从 ES 会话继承
swaysock=/run/0-runtime-dir/sway-ipc.0.sock
fullscreen=sway
ruffle_bin=/storage/roms/ports/ruffle/ruffle_desktop
fontconfig_file=/storage/roms/ports/ruffle/fonts.conf
pad_names=retrogame_joypad,joypad,gamepad
es_launch=none
es_unit=essway
```
