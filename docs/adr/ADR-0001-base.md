# ADR-0001：TreeOS 的底座与上游关系

- 状态：accepted
- 日期：2026-11-18
- 适用：全部设备

## 决策

1. **底座是自编 Debian 13 + 主线 Linux**，不是任何第三方发行版换皮。
2. **内核设备支持复用 ROCKNIX 的 GPL 补丁栈**（按 SoC/设备组织，pin 提交）；
   我们不再维护与之重叠的自有 6.12 兼容补丁。
3. **Arch R 仅作为 GPL-2.0 输入驱动的来源**（odroidgo3-joypad）；
   不使用其品牌、主题、logo、镜像素材（CC BY-NC-SA，禁止商用）。
4. **dArkOS 仅作用户态参考**（Debian rootfs / ES / 打包）；
   不采用其 4.4/5.10 内核作为底座。
5. 用户态 rootfs 共用；每 SoC 一个内核包；每设备一个启动包（DTB、面板、电源、输入、WiFi）。

## 后果

- 内核升级路径跟随 ROCKNIX 上游，减少自维护；
- 输入驱动来源与许可证需在 `THIRD_PARTY_NOTICES.md` 持续记录；
- 设备支持以「精确型号 + 启动包」声明，不用 SoC 名称代替；
- 任何文档不得再把上述四种关系混写为「系统底座」。
