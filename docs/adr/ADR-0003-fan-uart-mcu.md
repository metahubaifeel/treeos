# ADR-0003：风扇控制走独立 MCU + 串口，失效安全回 100%

- 状态：proposed
- 日期：2026-11-18

## 决策

- 风扇板使用带**硬件 PWM** 的 8 脚 MCU；SoC 侧通过 USB 转串口（首选）或可用 UART 发送
  目标频率/占空比，约 300ms 一次；MCU 回传转速与 5V 电压。
- 失效安全：5V 在、串口断 → 100%；5V 不在 → 0%。
- RK3326 的 UART 是固定引脚，不能把任意 GPIO 配成串口；不要占用调试 UART1，除非明确放弃调试口。

## 待验证

- 具体 UART 测试点、协议帧格式、波特率、风扇类型（2/4 线、FG）。
