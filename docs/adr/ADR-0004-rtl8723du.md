# ADR-0004：RTL8723DU（WiFi + BT）的驱动与固件

- 状态：proposed
- 日期：2026-11-18

## 决策

- WiFi：主线 `rtw88_8723du`（USB ID `0bda:d723`）；需要打开 `RTW88`/`RTW88_USB`/`RTW88_8723D`/`RTW88_8723DU`。
- 蓝牙：`btusb` + `btrtl`，固件 `rtl_bt/rtl8723d_fw/config`；注意 `FW_LOADER_COMPRESS` 与 `.zst` 固件。
- 电源：3.3V DCDC；模块上两个 0Ω 电阻不要同时贴，避免倒灌。
- 配置需按 **6.15.6** 重新核对，不再引用 6.12 配置结论。

## 状态

驱动方案已核对，未在实机验证。
