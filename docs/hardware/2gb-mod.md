# 2GB 改装与 Flash 验收协调（2026-11-18）

> 来源：Flash 移植 session 的请求 + 硬件线回答。
> 前提：1GB 是 TreeOS 基线；2GB 是**用户自行改装**，不是前提、不排期、不作为发布门槛。

---

## 一、Flash 线的请求

1. **2GB 改装的时间窗口**？改完后需要**独占设备 2–3 小时**做验收。
2. 改 2GB 时是否会同时动 **CMA / GPU 内存 / 散热**？这些直接影响 Panfrost 是否还超时。
3. 电量显示问题 treeos 已定位为 **6.15 驱动回归**，不需要硬件处理。

### 2GB 到位后的验收清单

- 3.2 进关卡稳定 20 分钟；
- RSS / swap 曲线；
- FN 开合 10 次；
- 退出回 ES 10 次；
- 存档往返 3 次；
- GPU 超时计数。

---

## 二、硬件线回答

- **时间窗口**：2GB 是拙木自行改装，**时间未定、不排期**；定下时间后，改完给 Flash 独占 2–3 小时。
- **2GB 改什么**：只换 RAM（2× 8Gb x16 DDR3L，BGA 重植）+ U-Boot DDR init。
- **CMA / GPU 内存 / 散热**：**不会自动改**，是独立决策。
  - 更多 RAM 可能减少 swap/OOM，但**不保证 Panfrost `gpu sched timeout` 消失**；那是驱动/调度问题，需要单独排查。
  - 改完要实测：CMA 大小、GPU 内存占用、温度/降频；如果同时改散热，单独记录。
- **电量显示**：按 6.15 驱动回归处理，硬件不动。
