# RK3566 / RK3562 到货前的准备（2026-11-18）

状态：两台设备**已采购、物流中**；型号未到，以下按“上游已有什么”整理，到货后按实际型号验证。

## RK3566（较乐观）

上游 Linux 已有这些掌机 DTS：

- Anbernic RG353P / RG353PS / RG353V / RG353VS
- Anbernic RG-ARC / RG-ARC-D / RG-ARC-S
- Powkiddy RGB30
- Powkiddy X55

ROCKNIX 另有一批面板、ADC keys、电池命名、WiFi、joypad、GPU OPP 补丁。
**路线**：到货确定型号 → 用上游 DTS + ROCKNIX 补丁 → 只维护设备启动包（DTB/面板/电源），用户态共用。
**风险**：具体批次的面板/摇杆/电池仍可能不同，必须逐台验证显示/输入/音频/休眠。

## RK3562（最慢）

上游只有：

- `rk3562.dtsi`（SoC）
- `rk3562-pinctrl.dtsi`
- `rk3562-evb2-v10.dts`（官方 EVB，不是掌机）

没有掌机 DTS，ROCKNIX 也没有 RK3562 设备包。
**路线**：必须先拿到厂商 BSP/DTS（或实机 dump），补面板、PMIC/充电、按键/摇杆、WiFi、SD；属于 bring-up，不设发布日期。
**结论**：3562 不作为近期发布承诺；到货后先做“能否启动 + 面板 + 输入”三件事。

## 到货后的验收顺序

1. 读型号/主板版本，dump 原厂 DTB，确认面板与按键；
2. 选上游最接近的 DTS，改 panel/regulator/input；
3. 启动 → 显示 → 输入 → 音频 → WiFi → 休眠；
4. 过一项记一项进 `STATUS.md`，未过不写“已支持”。

## 不承诺

- 任何未到货型号的具体日期；
- 克隆版/不同批次的兼容性；
- RK3562 的 Flash/PSP 性能。
