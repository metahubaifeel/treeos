# 怎么装游戏

## 方法一：直接进文件夹

把卡插电脑，打开 `EASYROMS` 盘，里面就是各个平台目录：

```
gba/  gb/  gbc/  nes/  snes/  megadrive/  n64/  nds/
psx/  psp/  arcade/  flash/  ports/
```

把游戏文件放进对应目录，拔卡回机器，重启 ES 就能看到。

## 方法二：丢进 import/（自动分类）

把文件、文件夹或 zip 放进这个 `import/` 目录，开机前会自动归档：

| 文件 | 去哪里 |
|---|---|
| `.gba` / `.gb` / `.gbc` | `gba/` `gb/` `gbc/` |
| `.nes` | `nes/` |
| `.smc` / `.sfc` | `snes/` |
| `.md` / `.gen` | `megadrive/` |
| `.gg` | `gamegear/` |
| `.nds` | `nds/` |
| `.n64` / `.z64` / `.v64` | `n64/` |
| `.cue` + `.bin` / `.chd` | `psx/` |
| `.iso` / `.img` | `psx/` |
| `.cso` / `.pbp` | `psp/` |
| `.zip`（主机 ROM） | 解压后按上表归档 |
| `.zip`（街机包） | **原样保留**进 `arcade/`，不要解压 |
| `.swf` | `flash/` |
| 含 `.swf` 的文件夹/zip | `flash/名字/`，并在 `ports/` 生成入口 |

规则：

- 街机 zip 不要手动解压，核心按 zip 文件名识别
- `iso` / `pbp` 分不清 PS1 还是 PSP 时：放进 `import/psp/` 或 `import/psx/` 子目录
- 多文件游戏（cue+bin、多盘）在 ES 里显示为一个文件夹，进去选 `.cue`
- 同名文件不会覆盖；结果看 `EASYROMS/import-report.txt`
- 存档、按键配置不受影响
- 这里只搬运你自己的文件，不下载、不内置任何游戏
